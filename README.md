每日自动运行并提交日报。

## 报告怎么看

- **当前最低价**：最近 7 天内出现过的最低到手价（`日期` 列为该价格的出现时间）。
- **历史最低**：该配置在监控期间出现过的最低价。
- **距历史新低**：`(当前价 / 历史最低 - 1)`，越接近 0% 越接近抄底点。
- **⚠️ 标记**：标题里没识别出配置，或最近报价已超过 30 天，下单前需人工核对。
- 同一型号的不同配置（16G+512G 与 16G+1T）**分开统计**，价格不可混比。

## 本地运行

```bash
npm install
node monitor.js          # 抓取 + 生成日报
node monitor.js --seed   # 只建基线，不告警（首次初始化用）
```

## 部署

### Windows（本机定时）

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup-task.ps1
```

注册每日 08:30 的计划任务：抓取 → 生成日报 → `git add/commit/push` 到 GitHub。

### GitHub Actions

`.github/workflows/daily.yml` 每天定时运行。**注意**：Actions 机房 IP 可能被慢慢买限流，若频繁失败以 Windows 定时任务为主。

## 数据来源与限制

- 主数据源：慢慢买公开搜索接口 `s.manmanbuy.com/Default.aspx`（聚合京东 / 天猫 / 淘宝 / 拼多多）。
- 慢慢买的历史曲线与「爆料」详情页需要登录或人机验证，京东 / 拼多多 / 值得买直连亦有反爬拦截，因此本项目**不抓取实时到手价**，只使用慢慢买已收录的历史成交价。
- 「历史新低」标签沿用慢慢买官方判定，权威性高于本地统计的「历史最低」。
- 本报告仅供选购参考，不构成价格承诺。

## 2026 年存储涨价周期下的购买建议

1. 优先京东自营 / 天猫旗舰店，拼多多百亿补贴售后风险自担。
2. 国补 + 平台券 + 88VIP 三重叠加是当前最大折扣来源。
3. 内存别省：2026 年 DDR5 涨幅超 3 倍，16G 是底线。
4. 双11 当天通常不更便宜（冲量在前半段），建议 10 月底至 11 月 3 日下手。
5. 存储紧缺预计延续到 2027 下半年，「等降价」不成立。
